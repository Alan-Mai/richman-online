# 遊戲規則規格

這份文件是規則引擎的唯一依據。內容請以**實際遊玩原版觀察**為準，不要憑記憶。
每條規則標示狀態：`✅ 已確認`、`❓ 待確認`、`⚙️ 參數化`（數值可在 RuleConfig 調整）。

Claude Code：遇到 `❓ 待確認` 時不要自行決定，先詢問或做成參數。

> **暫定值說明**：標 ⚙️ 且寫有「暫定」的數值是 Phase 2 為了讓引擎能跑而填的，**非原版數值**。
> 實測原版後改成觀察值並標 ✅；括號內是對應的 `RuleConfig` 欄位名稱（草稿）。

## 1. 基本設定
| 項目 | 值 | 狀態 |
|---|---|---|
| 玩家人數 | 暫定 2–4（`minPlayers` / `maxPlayers`），非原版 | ⚙️ |
| 起始現金 | 暫定 20,000（`startingCash`），非原版 | ⚙️ |
| 起始存款 | 暫定 20,000（`startingDeposit`），非原版 | ⚙️ |
| 起始點數 | 暫定 0（`startingPoints`），非原版；Phase 2 不使用 | ⚙️ |
| 勝利條件 | 暫定「其他玩家全破產」（`winCondition: 'lastStanding'`），非原版預設；另可選限時資產最高 / 目標資產 | ⚙️ |

## 2. 回合流程
1. 回合開始：結算狀態效果（住院、坐牢、神明附身剩餘回合……） ❓
2. 可使用道具卡（擲骰前） ❓
3. 擲骰 ⚙️ 骰子數為玩家屬性 `player.diceCount`，暫定預設 1（`RuleConfig.defaultDiceCount`），6 面（`diceFaces: 6`），非原版
   - ❓ 原版可能有交通工具影響骰子數，待實測
   - 遙控骰子 ❓
4. 移動（逐格經過時的觸發：銀行、路障、地雷……） ❓
   - 經過起點 ⚙️ 暫定獲得 2,000 現金（`passStartBonus`），非原版
5. 停留格處理
6. 回合結束

## 3. 地產
| 項目 | 規則 | 狀態 |
|---|---|---|
| 購地價格 | 暫定由地圖資料每格的 `price` 決定（內建測試地圖自訂），非原版 | ⚙️ |
| 加蓋等級與費用 | 暫定最高 5 級（`maxLevel`）；每級費用 = 地價 × 0.5（`upgradeCostRatio`），非原版 | ⚙️ |
| 過路費公式 | 暫定 地價 × 倍率[等級]，倍率 0–5 級 = 0.1 / 0.3 / 0.6 / 1.0 / 1.5 / 2.0（`rentRatioByLevel`），非原版 | ⚙️ |
| 連續地段加成 | 暫定關閉（`streetBonus: 'none'`），非原版 | ⚙️ |
| 停在自己的地 | 暫定可付費加蓋一級，也可放棄（`upgradeOnOwnTile: true`），非原版 | ⚙️ |

## 4. 特殊格子
每種格子一節：名稱、觸發時機（經過/停留）、效果、相關數值。
- 銀行 ❓
- 醫院 ❓
- 監獄 ❓
- 道具店 ❓
- 機會 ❓
- 命運 ❓
- 新聞 ❓
- 彩券 ❓
- 魔法屋 ❓
- 公園 / 空地 ❓

## 5. 卡片
格式：

```
### 卡片名稱
- 類型：道具卡 / 機會 / 命運
- 價格（點數）：
- 使用時機：擲骰前 / 任何時候 / 被動
- 目標：自己 / 指定玩家 / 格子 / 範圍
- 效果：
- 持續回合：
- 與其他效果的互動：
- 狀態：❓
```

## 6. 股票
- 股票數量、開盤價、漲跌規則、交易時機、手續費 ❓

## 7. 神明
格式同卡片：名稱、附身方式、持續回合、效果、如何驅離。

## 8. 破產
- 現金不足時 ✅（專案指定規則）：
  1. 不足的部分自動從存款扣除
  2. 存款也不夠 → 直接破產
  - 不自動賣地、不拆房
- 破產後地產處理 ✅（專案指定規則）：全部收回為無主空地，房屋清除
- 欠款對象拿到的金額 ❓（例如：破產者剩餘現金＋存款全數給債權人，或不給）
- 股票上線後是否納入償債 ❓（Phase 5 再決定）
